**LewiHouse Web Portal** is the official public-facing showcase and reservation platform for the LewiHouse boarding house (*kostan*) property network. Featuring rich visual aesthetics, interactive photo galleries, immersive virtual tours, and a Gemini-powered AI room concierge, it connects prospective residents directly with verified accommodations.

---

## 🌟 Key Features

- **Property & Room Showcase**: High-resolution gallery featuring Standard, Deluxe, and Executive room types with amenity checklists (AC, WiFi, ensuite bathroom, water heater, work desk).
- **AI Room Concierge (Gemini API)**: Multimodal AI virtual assistant answering visitor inquiries on rules, pricing, surrounding points-of-interest, and availability.
- **Direct WhatsApp Reservation**: One-click booking request generator that formats room preference, check-in dates, and special requests into a ready-to-send WhatsApp message.
- **Interactive Neighborhood Guide**: Distance and commute times to nearby universities, business centers, hospital hubs, and transit stations.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/aliakhmadfauzie/lewihouse-web.git
cd lewihouse-web

# Install dependencies
npm install

# Run development server
npm run dev

# Production build
npm run build
```
